# Prints de interação

O portal UniCV solicita cinco prints de interação/adesão da comunidade.

Inserir somente capturas reais, por exemplo:
1. Curtidas da publicação.
2. Comentários.
3. Compartilhamentos.
4. Visualizações da publicação.
5. Visualizações/clones do repositório.

Não fabricar números, nomes de usuários ou métricas. Caso alguma evidência ainda não exista, manter o item pendente.
